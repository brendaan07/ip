## Use of ChatGPT in this iP

I used ChatGPT for AI assistance in this iP.

I asked it to help me **clean up my full commit messages** and **PR request descriptions**.

ChatGPT helped me generate code for the `load` method in `Storage` to handle loading standardised 
formats from `data.txt` into my UI. It also helped me generate code for the **input and output formats** for time 
and data handling increments.

I consulted ChatGPT for help in **merging my JavaFX UI with my application**, including refactoring 
my `Goat.main` method into a `getResponse` method to integrate with the GUI. It also helped me generate 
code for **JUnit testing**.

In terms of errors, ChatGPT helped me identify **SLAP violations** and handle **user input errors** for 
differences in date and time formats.

ChatGPT was effective in providing code for **common templates** like date/time formatting and storage 
handling. However, at times it did not fully understand the **interconnectivity** of my code when handling 
classes like `TaskList` and `Goat`. Hence, coding some logic and fixing errors by hand was faster 
and allowed me to **understand my codebase fully**.
